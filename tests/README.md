# Tests

Die vollständige Anleitung steht unter [Prüfungen](../docs/Pruefungen.md).

Schnellprüfung ohne Bus:

```sh
python tools/pruefen.py
```

Die vollständigen Originalaufnahmen werden nicht mitgeliefert.
Die Basisprüfung verwendet eine synthetische Hauptwertdatei und das vorhandene Display-Testbild.
Die zusätzlichen Wiedergabeprüfungen nehmen die Originalaufnahmen als Argumente entgegen.
