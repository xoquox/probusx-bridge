# Erzeugte Firmwareabbilder

Nach einem vollständigen Build enthält dieser Ordner:

- `probusx-bridge-waveshare-ota.bin`
- `probusx-bridge-waveshare-usb.bin`
- `sdkconfig.used`
- `SHA256SUMS`

Die Dateien werden aus den Quellen erzeugt und von Git nicht übernommen.
Der GitHub-Build stellt die Dateien als Build-Ergebnis bereit.
Ein vorliegendes Projektpaket kann zusätzlich geprüfte Abbilder enthalten.
Die Bauanleitung steht unter [Entwicklung](../../docs/Entwicklung.md).
